# Tamima Creative Portfolio

A React + Vite portfolio built around Tamima's original photography and social-media work.

## Run locally

1. Install Node.js (LTS): https://nodejs.org/
2. Open this project folder in VS Code.
3. Open the VS Code terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (normally `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/main.jsx` — website content and React components
- `src/styles.css` — all visual styling and responsive rules
- `public/assets/` — original photography supplied for the portfolio

## Important links

The social links are stored near the top of `src/main.jsx` inside the `socials` object. Update them there if needed.
